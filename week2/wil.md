#터미널에서
- cd
- pwd
위의 명령어들을 비롯 디렉토리를 오갈 수 있는 명령어 문법과
'git clone'이라는 github 내의 프로그램을 받아 볼 수 있는 명령어를 알게 되었다.

#HTML에서
HTML의 구체적인 뜻과 하이퍼텍스트 삽입 방법에 대해 학습했다.
물론 index.html은 생략한다는 쏠쏠한 정보도 알 수 있었다.

#CSS
html에 스타일을 입히는 CSS를 맛보았다. 

#GitHub Desktop
기존에는 터미널에 명령어를 적거나 Visual Studio 내에서 깃을 다루었는데
이런 확장프로그램이 있었다는 사실을 새로이 알게되었다.
